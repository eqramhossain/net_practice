Alright — let’s treat Level 7 of NetPractice like a real networking lab and break it down step by step, slowly and clearly.

🧠 First: What Level 7 is testing


At this level, you’re no longer just assigning IPs. You’re expected to understand routing logic deeply:

  • Multiple routers involved

  • Several subnets

  • Correct routing tables required

  • Proper use of default routes vs specific routes


👉 In short: “How does a packet know where to go across multiple networks?”

🧩 The core idea (VERY important)


A machine (host or router) follows this logic when sending a packet:

  1. Is the destination in my subnet?

    • YES → send directly

    • NO → send to a router (gateway)

  2. Router receives the packet:

    • Checks its routing table

    • Chooses the best matching route

    • Forwards the packet to the next hop

🔥 The difficulty in Level 7


You usually get something like:

Host A ── Router R1 ── Router R2 ── Host B

But with:

  • Different subnet masks

  • Missing routes

  • Possibly wrong configurations


👉 Your job is to:

  • Fix IPs / masks

  • Complete routing tables

  • Ensure A can reach B AND B can reach A

⚠️ The most common mistake


People only fix the forward path:

A → B ✅ works

But forget the return path:

B → A ❌ fails

👉 Networking ALWAYS requires bidirectional connectivity

🛠️ Step-by-step method to solve Level 7


1. Identify each subnet


For every interface:

  • Apply mask

  • Compute network address


Example:

IP: 192.168.1.10
Mask: 255.255.255.0

→ Network: 192.168.1.0/24

2. Group interfaces in the same subnet


If two interfaces:

  • Have the same network address

    👉 They are directly connected

3. Check each device


🖥 Host:

Needs:

  • IP

  • Mask

  • Default gateway


👉 Ask yourself:


“If I send to another network, where do I send the packet?”


Answer = router interface

📡 Router:

Needs:

  • IP on each interface

  • Routing table entries

4. Build routing tables (THIS IS KEY)


Each router must know:

  • Directly connected networks → automatic

  • Remote networks → must add routes

💡 How to think like a router


Ask:


“If I receive a packet for network X… where do I send it?”

🧪 Example reasoning (simplified)


Let’s say:

  • A → network 10.0.0.0/24

  • B → network 20.0.0.0/24


Router in between:

  • Interface 1: 10.0.0.1

  • Interface 2: 20.0.0.1

On Host A:

Default gateway → 10.0.0.1

On Router:


Already knows:

10.0.0.0/24 → directly connected
20.0.0.0/24 → directly connected

On Host B:

Default gateway → 20.0.0.1

✔ Now communication works BOTH ways

⚠️ In Level 7, routers are chained


So you must think like:

A → R1 → R2 → B

So:


On R1:


Needs route to B’s network via R2


On R2:


Needs route to A’s network via R1

🧠 Golden rule


👉 Every router must know how to reach:

  • All remote networks


👉 Every host must know:

  • Where to send outside traffic

🚨 Debug strategy (VERY IMPORTANT)


When it fails, simulate mentally:


Forward:

A → ? → ? → B

Reverse:

B → ? → ? → A

👉 Find where it breaks
